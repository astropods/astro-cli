# InlineBadge

Outlined mono-text pill for classification and category labels on cards. Uses teal accent color with light/dark surface adaptation.

## Import

```tsx
import { InlineBadge } from "@/components/InlineBadge"
```

## Usage

```tsx
<InlineBadge>API Agent</InlineBadge>
```
