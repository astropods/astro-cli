# AgentCard

A card component for the agent marketplace grid. Displays an agent's name, description, integration icons, category badges, and install/view-details actions.

## Import

```tsx
import { AgentCard } from "@/components/AgentCard"
```

## Usage

```tsx
<AgentCard
  slug="acme/customer-insight-engine"
  account="acme"
  name="Customer Insight Engine"
  description="Analyzes customer feedback to surface actionable insights and trends."
  integrations={["Slack", "GitHub", "Linear", "Notion"]}
  categories={["Analytics"]}
/>
```

Integration names are resolved to icons via `getIntegrationItems` from `@/lib/integrationIcons`. Names without a known icon are filtered out. The `IntegrationIconStack` shows up to 3 icons with a "+N" overflow indicator.

## Responsive Behavior

The card uses container queries (`@container`) so the action buttons stack vertically when the card is narrow and sit side-by-side when there's enough room.
