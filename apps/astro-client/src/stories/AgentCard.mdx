# AgentCard

A card component for the agent marketplace grid. Displays an agent's avatar, name, description, and category badges. The entire card is a link to the agent detail page.

## Import

```tsx
import { AgentCard } from "@/components/AgentCard"
```

## Usage

```tsx
<AgentCard
  slug="acme/customer-insight-engine"
  account="acme"
  name="Customer Insight Engine"
  description="Analyzes customer feedback to surface actionable insights and trends."
/>
```
