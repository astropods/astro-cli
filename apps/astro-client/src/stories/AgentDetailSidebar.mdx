# AgentDetailSidebar

The right-hand sidebar shown on the agent detail page. It composes several sub-components into a sticky card containing an install CTA, author info, version stats, required apps, and permissions.

Hidden on viewports below `lg` via `hidden lg:block`.

## Import

```tsx
import { AgentDetailSidebar } from "@/components/agent-detail"
```

## Usage

```tsx
<AgentDetailSidebar
  agent={agent}
  description="Analyzes customer feedback to surface actionable insights."
  integrations={["Slack", "GitHub"]}
  capabilities={["Read Slack messages", "Access GitHub repositories"]}
  initialAccountData={accountData}
/>
```

# Sub-components

Each section of the sidebar is a standalone component that can be used independently. They all use `SidebarSection` to render a consistent title label above their content.

---

## SidebarSection

A shared wrapper that renders a `text-muted-foreground` title label above any content. Used by all sidebar sub-components to ensure consistent heading style.

```tsx
import { SidebarSection } from "@/components/agent-detail"
```

```tsx
<SidebarSection title="My Section">
  <p>Any content goes here.</p>
</SidebarSection>
```

## SidebarAuthor

Shows the agent creator's avatar (or initials fallback), display name, and `@handle`.


## RequiredAppsList
