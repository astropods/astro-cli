# Integration Icons

A centralized registry mapping integration names to their SVG icons. Use this instead of importing individual SVG components throughout the app.

## Import

```tsx
import { integrationIconMap, getIntegrationItems } from "@/lib/integrationIcons"
```

## Available Icons

<Canvas of={IntegrationIconsStories.Catalog} />

## Usage with IntegrationIconStack

`getIntegrationItems` takes an array of integration name strings, filters to those with known icons, and returns items ready for `IntegrationIconStack`:

```tsx
import { getIntegrationItems } from "@/lib/integrationIcons"
import { IntegrationIconStack } from "@/components/IntegrationIconStack"

const items = getIntegrationItems(["Slack", "GitHub", "Jira"])
// "Jira" is filtered out (no icon), returns Slack + GitHub

<IntegrationIconStack integrations={items} max={3} />
```

## Direct icon lookup

Use `integrationIconMap` when you need a single icon by name:

```tsx
import { integrationIconMap } from "@/lib/integrationIcons"

const slackIcon = integrationIconMap["Slack"] // <Slack /> ReactNode
```

## Adding new icons

1. Install the SVG via shadcn: `bun x shadcn@latest add @svgl/<name>`
2. Add the entry to `integrationIconMap` in `src/lib/integrationIcons.tsx`
