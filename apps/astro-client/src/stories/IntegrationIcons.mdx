# Integration Icons

Integration icons are served from the CDN (`assets.astropods.ai`) in production and from the repo-root `assets/integrations/` folder in local dev. Icons are only rendered for **known** integrations (those in the `agent_card_integrations.json` registry).

## Available Icons

<Canvas of={IntegrationIconsStories.Catalog} />

## Usage with IntegrationIconStack

`getIntegrationItems` filters to integrations with `known: true` and returns items ready for `IntegrationIconStack`:

```tsx
import { getIntegrationItems } from "@/lib/integrationIcons"
import { IntegrationIconStack } from "@/components/IntegrationIconStack"

const items = getIntegrationItems(integrations)

<IntegrationIconStack integrations={items} max={3} />
```

## Adding new icons

1. Add the SVG to `assets/integrations/light/` and `assets/integrations/dark/` at the repo root
2. Ensure the integration is registered in `packages/astro-spec/agent_card_integrations.json`
