# StatusBadge

A color-coded pill for displaying status. Each variant includes a background, text color, border, and optional leading dot indicator.

## Import

```tsx
import { StatusBadge } from "@/components/StatusBadge"
```

## Usage

```tsx
<StatusBadge variant="active" />
<StatusBadge variant="error" showDot={false} />
```

## Variants

### Active

Green badge for running or healthy states.
