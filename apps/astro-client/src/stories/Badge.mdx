# Badge

A generic pill badge for labels, categories, and statuses. The `default` variant provides a neutral outline style suitable for category tags. Status variants (active, pending, etc.) include color coding and support an optional leading dot.

## Import

```tsx
import { Badge } from "@/components/Badge"
```

## Usage

```tsx
<Badge>Marketing</Badge>
<Badge variant="active" showDot>active</Badge>
```

Use for category labels, tags, or any neutral metadata.
