# PageTitle

A page-level heading with an optional subtitle and action slot.

## Import

```tsx
import { PageTitle } from "@/components/PageTitle"
```

## Usage

```tsx
<PageTitle
  title="Available Agents"
  subtitle="Browse agents available within your organization"
  actions={<Button>Request agent</Button>}
/>
```
