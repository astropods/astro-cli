# Sidebar

The application sidebar built on [shadcn/ui Sidebar](https://ui.shadcn.com/docs/components/sidebar) primitives. It provides primary navigation, collapsible agent lists, resource links, a CTA, and user authentication controls.

## Architecture

The sidebar is composed of three reusable sub-components:

<Md>{`| Component | Description |
|---|---|
| \`SidebarNavGroup\` | Data-driven nav list with optional group label, icons, and external link support |
| \`SidebarCollapsibleGroup\` | Expandable/collapsible section with chevron animation |
| \`SidebarUserMenu\` | Auth footer with loading, signed-in, and signed-out states |`}</Md>

These are assembled in `AppSidebar`, which is a presentational component that receives auth state via props.

## Import

```tsx
import { AppSidebar } from "@/components/AppSidebar"
import { SidebarProvider, SidebarInset } from "@/components/ui/sidebar"
```

## Usage

```tsx
<SidebarProvider>
  <AppSidebar
    user={user}
    isAuthenticated={isAuthenticated}
    isLoading={isLoading}
    onSignIn={login}
    onSignOut={logout}
    onTalkToAstro={handleTalkToAstro}
  />
  <SidebarInset>
    <main>{/* page content */}</main>
  </SidebarInset>
</SidebarProvider>
```

## Nav Group

A reusable navigation group that renders a list of links. Supports optional group labels, icons, external links, and active state.

```tsx
import { SidebarNavGroup } from "@/components/sidebar/SidebarNavGroup"
```

```tsx
<SidebarNavGroup
  label="Resources"
  items={[
    { label: "Docs", icon: DocumentTextIcon, to: "https://docs.example.com", external: true },
    { label: "Settings", icon: CogIcon, to: "/settings", isActive: true },
  ]}
/>
```

## Props

### AppSidebar

<Md>{`| Prop | Type | Default | Description |
|---|---|---|---|
| \`user\` | \`User \\| null\` | \`undefined\` | The authenticated user object |
| \`isLoading\` | \`boolean\` | \`false\` | Show loading state in footer |
| \`isAuthenticated\` | \`boolean\` | \`false\` | Whether the user is signed in |
| \`onSignIn\` | \`() => void\` | — | Called when Sign In is clicked |
| \`onSignOut\` | \`() => void\` | — | Called when Sign Out is clicked |
| \`onTalkToAstro\` | \`() => void\` | — | Called when the CTA button is clicked |`}</Md>

### SidebarNavGroup

<Md>{`| Prop | Type | Default | Description |
|---|---|---|---|
| \`label\` | \`string\` | — | Optional group label displayed above the items |
| \`items\` | \`NavItem[]\` | — | Array of nav items to render |`}</Md>

### SidebarCollapsibleGroup

<Md>{`| Prop | Type | Default | Description |
|---|---|---|---|
| \`label\` | \`string\` | — | Group label (also the collapse trigger) |
| \`items\` | \`CollapsibleItem[]\` | — | Array of items to render |
| \`defaultOpen\` | \`boolean\` | \`true\` | Whether the section starts expanded |`}</Md>
