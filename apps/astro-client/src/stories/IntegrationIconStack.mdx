# IntegrationIconStack

A compact row of overlapping integration icons with an optional "+N" overflow count. Built on top of `IntegrationBadge`.

## Import

```tsx
import { IntegrationIconStack } from "@/components/IntegrationIconStack"
```

## Usage

```tsx
<IntegrationIconStack
  integrations={[
    { name: "Slack", icon: <Slack /> },
    { name: "GitHub", icon: <GithubLight /> },
    { name: "Linear", icon: <Linear /> },
    { name: "Notion", icon: <Notion /> },
    { name: "Google Drive", icon: <Drive /> },
  ]}
  max={3}
/>
```

## Default

Shows up to 3 icons with a "+N" overflow indicator.
