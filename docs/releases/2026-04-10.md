# Release — 2026-04-10

## GitHub-Connected Builds

Full end-to-end GitHub integration for automated agent builds. Connect a repo from the blueprint detail page; pushes trigger in-cluster BuildKit jobs that build and push the agent image automatically.

- Builds run on dedicated nodes with ECR layer caching and a custom `buildkitd` ConfigMap
- Build logs stream live in the sidebar and auto-refresh while the job is running
- Webhook delivery proxied through the backend; shell blueprint created before the first build completes
- A repo can only be linked to one agent per account — conflict returns a clear error
- Rapid pushes cancel in-flight builds end-to-end (DB, River job, K8s job)
- Build token fetch fixed for WorkOS org-scoped sessions (`workos_org_id` now stored and passed)

## Messaging Web Adapter Authentication

ALB-level OIDC authentication for the messaging ingress via WorkOS. Opt-in per deployment via `interfaces.auth.web.type: oidc`. The deploy form shows a "Require authentication" toggle; pre-fills correctly when editing an existing authenticated deployment. Requires `MESSAGING_OIDC_*` server env vars.

## Playground Bundled into Messaging

The standalone playground container, submodule, and `ast playground` CLI command are removed. The messaging binary serves the UI when `WEB_SERVE_PLAYGROUND=true`. `ast dev` handles this automatically; the chat open button links directly to the messaging URL.

## Other Features

- **Default org in dashboard** — star button pins preferred account to `localStorage`; validated on load
- **`ast config --save`** — exports stored vars to a `.env` file
- **VaultPicker** — new variable can be created inline from the picker
- **`@astropods/theme`** — published to npm via OIDC workflow
