# Bound review queue trace queries

## Summary

Large trace histories can cause Langfuse to reject review queue requests before Astro applies local judgment filters. Review queue scans now query a bounded recent window.

## Design

The review queue uses the 30 days before its snapshot timestamp as the Langfuse query window. Cursor requests retain the same snapshot, so pagination remains stable while reviewers move through the queue. Prediction filters use the same window when selecting candidates from Astro's database.

The queue still scans up to three trace pages per request and applies judgment and prediction filters from Astro's database.

## Migration

No migration is required. Review queues show traces from the most recent 30-day window.
