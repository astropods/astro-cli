# Summary

Adds search, category filters, and sorting to the Explore community blueprints page so visitors can browse a growing catalog by relevance and activity signals.

# Design

Explore now owns a compact toolbar directly under the title, using the same search input and dropdown treatment as the Agents and Blueprints pages. The page filters loaded public blueprints locally by search text and selected categories before handing them to the shared blueprint list view.

Category filters are derived from blueprint card tags and live in a multi-select filter dropdown beside the sort control. Each category displays the number of loaded blueprints with that tag using a readable display label, and multiple selected categories use inclusive matching. The shared multi-select primitive now includes an explicit remove-filters action and a scrollable list slot, with Storybook variants covering default, selected, scrollable, and no-color states. Sorting supports Most deploys, Most hearted, Last updated, and Name (A-Z). Last updated uses the newest version `published_at`; heart sorting uses `heart_count`; missing counts fall back to zero with name-based tie breaking so ordering remains deterministic.

# Migration

No user migration required.
