# fix(unfurl): correct font copy destination in SSR build pass

## Summary

Badge card rendering was broken in prod — fonts were not injected into the SSR bundle, causing blank text in the SVG card. This is a follow-up to `sohum/unfurlfix` which introduced the `copyBlueprintFonts` Vite plugin.

## Design

React Router v7 runs two Vite build passes:

```
client pass → outDir = build/client
server pass → outDir = build/server
```

The previous plugin wrote to `outDir + "/server/assets/fonts"`. During the server pass that resolved to `build/server/server/assets/fonts` — one level too deep. The runtime loads fonts from `build/server/assets/fonts`, so nothing was found.

Fix: gate the copy on `config.build.ssr` (truthy only during the server pass) and write to `outDir + "/assets/fonts"` directly — since `outDir` is already `build/server` at that point.

```ts
closeBundle() {
  if (!resolvedConfig.build.ssr) return;                          // server pass only
  const dest = path.resolve(resolvedConfig.build.outDir, "assets/fonts"); // build/server/assets/fonts ✓
  ...
}
```

## Migration

No action required. Deploy `astro-client`.
