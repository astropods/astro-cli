## Summary

Adds Playwright e2e coverage for the two highest-value user journeys that shipped recently but had no automated tests: the full onboarding flow (create blueprint → deploy agent) and the deployed-agent detail pages (Monitor, Deployments, Logs tabs).

## Design

**Mock backend extensions (`e2e/mock-backend.ts`)**

Five new endpoint stubs were added to support the new tests:

- `GET /api/v1/agents` — global blueprint list (used by the blueprint detail page loader)
- `GET /api/v1/accounts/:account` — account detail (GET was previously unhandled; only PUT/PATCH existed)
- `GET /api/v1/agents/:account/:name/deployment/history` — returns a single synthetic current-revision record derived from the live deployment state
- `GET /api/v1/deployments/:id/observability/(metrics|summary|traces)` — returns realistic fixture data: 150 total traces, 523ms avg latency, 2% error rate, and two named trace entries
- `GET /api/v1/deployments/:id/logs` — returns plaintext log lines (`Starting agent server on :8080`, etc.)

Two existing stubs were extended:

- `templateMatch` now falls back to a minimal `OPENAI_API_KEY`-only template for any name in `createdBlueprints`, enabling the deploy form to load after blueprint creation
- `dep-slack-full-1` now ships with one `agent` workload + container so the LogsTab has a container to auto-select on mount

**`e2e/onboarding-flow.spec.ts`** — 2 tests

1. *Full onboarding*: `/new/custom` → fill name → create → publishing panel → review panel → auto-nav to blueprint detail → click "Deploy this agent" (`.last()` to target the desktop sidebar link) → deploy form → fill `OPENAI_API_KEY` → submit → assert POST payload → `waitForURL("**/dashboard*")`
2. *Blueprint detail deploy button*: navigate directly to `/testuser/code-reviewer` → assert "Deploy this agent" link → click → `waitForURL("**/deploy/testuser/code-reviewer")`

**`e2e/monitor-deployments.spec.ts`** — 4 tests

1. *Monitor headline metrics*: `?tab=monitor` → assert `TOTAL REQUESTS`, `150`, `523ms`, `2.0%`
2. *Trace row → side panel*: click "chat completion" row → assert input/output from `TraceDetailPanel`
3. *Deployments tab*: default tab → assert stat cards (`CURRENT BUILD`, `build-12`, `SERVICES`) and auto-opened `agent` workload accordion
4. *Logs tab*: `?tab=logs` → assert log lines from the mock plaintext response

**`e2e/deployment-lifecycle.spec.ts`** — 4 tests

1. *Pause*: click "Pause" → POST `/deployments/:id/stop` → assert button changes to "Resume"
2. *Resume*: pause then click "Resume" → POST `/deployments/:id/wakeup` → assert button returns to "Pause"
3. *Restart*: EllipsisHorizontal KebabMenu → "Restart deployment" → confirm dialog → POST `/deployments/:id/restart`
4. *Configure side panel*: click "Configure" → panel loads OPENAI_API_KEY prefilled → change value → "Save & Redeploy" → assert new value in POST payload

**`e2e/blueprint-settings.spec.ts`** — 2 tests

1. *Avatar upload*: blueprint detail camera button → dialog "Upload blueprint image" → `setInputFiles` minimal PNG → cropper phase → "Upload" → POST `/agents/:account/:name/avatar` → dialog closes
2. *Archive*: account profile → "Blueprint options" dropdown → "Archive agent" → dialog → check checkbox + type name → "Archive blueprint" → POST `/agents/:account/:name/archive`

**Additional additions to existing files:**
- `monitor-deployments.spec.ts`: window switch test — select "Last 1 hour" from the `<Select>` combobox → assert a new `/observability/summary` GET fires
- `onboarding-flow.spec.ts`: "Continue setup →" test — `page.route` delays the blueprint poll by 4s so the review panel stays visible; asserts the button exists and clicking it navigates to blueprint detail

**Additional mock backend stubs added:**
- `POST /api/v1/deployments/:id/stop` → sets `status: "stopped", replicas: 0, ready: 0`
- `POST /api/v1/deployments/:id/wakeup` → restores `status: "healthy", replicas: 1, ready: 1`
- `POST /api/v1/deployments/:id/restart` → returns `{ status: "restarting", pods: [] }`
- `POST /api/v1/agents/:account/:name/avatar` → returns `{ avatar_url: "..." }`
- `POST /api/v1/agents/:account/:name/archive` → returns `{ ok: true }`
