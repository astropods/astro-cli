# Fix: Profile page terminology

## Summary

The profile page used inconsistent terminology — "Installed agents" for deployments and "No agents installed" for the empty state — that didn't match the rest of the product.

## Design

Updated labels on the profile page to align with product-wide terminology:

- "Installed agents" → "Deployed agents"
- "No agents installed" → "No agents deployed"

## Migration

No changes required.
