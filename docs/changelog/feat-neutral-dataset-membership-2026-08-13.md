# Neutral dataset membership

## Summary

The dataset table now presents traces as members of a dataset rather than as good or bad judgments.

## Design

The table loads all dataset items without a verdict filter and removes verdict chips, columns, copy, and editing controls. Criteria, reviewer attribution, pagination, trace expansion, and removal remain available. Existing legacy good and bad rows are preserved and displayed neutrally; no data or metadata migration occurs.

## Migration

No action is required.
