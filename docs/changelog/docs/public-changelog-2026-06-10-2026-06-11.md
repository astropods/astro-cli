# Public Changelog — June 10, 2026

## Summary

Add a public-facing changelog entry for the 2026-06-04 and 2026-06-10 releases, combining both into one user-facing post for `docs-public/fern/docs/changelog/`. The internal release notes are written for the team (architecture, commit ranges, internals); this post is rewritten for external readers — capabilities and visible behavior only, no internal mechanics.

## Design

The editorial rules applied throughout, derived from prior feedback on this site:
- Lead with what users can now *do*, not what changed in the UI.
- Drop anything not visible to a user: endpoint splits, table renames, codec collisions, CI changes, submodule bumps, refactors.
- Skip non-customer-facing features (multi-cluster, EU badge, OpenMeter sync).

The headline is **AI Gateway** — the only net-new capability across both releases. Secondary themes fold under it: blueprint usage visibility, per-deployment Insights, Slack identity, and a tighter status/traces/logs experience.

Layout uses a two-column flex pattern with images in the margin, alternating left/right per section so the page doesn't feel one-sided. Inline styles are plain HTML strings (`style="..."`) rather than JSX expressions (`style={{}}`) because Fern's MDX parser silently drops the latter.
