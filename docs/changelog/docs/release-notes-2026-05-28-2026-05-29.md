# Public changelog: May 28, 2026 release

## Summary

Adds the first real public changelog entry covering the May 23–28 release ("Know Your Agents") and turns on the Fern changelog section so the entry actually renders on docs.astropods.com.

## Design

Fern has a first-class changelog feature wired to a folder of dated `.mdx` files. The repo already had the folder (`docs-public/fern/docs/changelog/`) and the navigation entry, but the navigation entry was commented out in `docs.yml`, so nothing rendered. This change:

- Uncomments the `Changelog` section under the `home` tab in `docs-public/fern/docs.yml` and points it at `docs/changelog`.
- Removes the placeholder `02-17-2026.mdx` ("Initial release of public-facing Astro AI documentation") that was the only entry in the folder.
- Adds `2026-05-28 - Know Your Agents.mdx` with frontmatter (`title`, `slug`, `tags`) and the user-visible portion of the May 23–28 release: agent sizing + persistent volumes, pod workload metrics, network traffic on the Monitor page, Insights per-user view + instant range switching, Agents page speed, deploy form interface awareness, inline secrets preservation, public URL readiness, connectors settings page, CLI cancel UX + auth refresh.

Internal-only items (multi-cluster operator configuration, infra usage API internals, design specs) are intentionally excluded.

## Migration

None — pure docs change.
