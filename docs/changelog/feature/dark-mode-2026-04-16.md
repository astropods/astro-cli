# Dark mode theming system

## Summary

Adds dark mode support to astro-client, gated behind the existing `theming` experiment flag in Settings > Experiments. When enabled, users can switch between Light, Dark, and System themes from the user menu. All changes are inert when the flag is off.

## Design

**Theme infrastructure** — A `useTheme` hook (`lib/theme.ts`) manages three modes: light, dark, and auto (system preference). The preference is persisted to localStorage and synced across tabs. A blocking inline script in the SSR `<head>` reads the preference before first paint to prevent a flash of light mode.

**Dark semantic tokens** — Updated `astro-theme/semantic.ts` dark-mode tokens:
- `muted` changed from `teal-800` to a very dark teal (`oklch(17% 0.022 198.266)`) for subtle contrast against the surface
- `muted-foreground` changed from `stone-600` to `teal-100` for readable secondary text
- `faint-foreground` changed from `stone-700` to `teal-300` for label legibility

**Background color fixes** — Replaced `dark:bg-background` (teal-950) overrides on the header, detail page, side panel, and configure panel with `bg-surface`, which resolves correctly in both modes via CSS variables. Replaced `bg-muted` on the detail view content areas with `bg-surface`. Replaced hardcoded `bg-stone-50` on env vars and domains subtables with `bg-background`.

**Theme switcher UI** — Three icon buttons (sun/moon/monitor) placed inline to the right of the Sign Out button in the user dropdown, separated by a vertical divider.

## Migration

No action required. The feature is off by default behind the `theming` experiment flag.
