# Dataset item dropdown menu updates

## Summary

Reviewers can now manage a judged dataset item directly from its three-dot dropdown menu.

## Updates

- Change an item's verdict (Good/Bad) from the menu, with the current verdict highlighted.
- Edit an item's judgment criteria in place, using the same pills as the review queue.
- Changing the verdict keeps the menu open so criteria can be adjusted in the same step, and resets the selected criteria to match.
- Save is enabled only when the criteria change, and confirms with a success toast.
- Removed the Neutral option; use "Remove from dataset" to return an item to the review queue.

## Also

- Toasts now follow the app's light/dark theme.
- The review queue's criteria confirmation button is now labeled "Save".

## Migration

None.
