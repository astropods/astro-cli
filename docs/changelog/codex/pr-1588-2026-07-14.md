# Configure page blueprint build picker

## Summary

Improves the agent configure page so users can see and select the exact published blueprint build an agent should run. The picker now shows build title, build number, latest/current state, push time, and an inline new-build signal.

## Design

The configure form now uses the shared select component for blueprint build selection instead of a custom menu. Deployment status badge styling is shared between deployment cards and the picker so current-build state stays visually consistent.

The shared select component also constrains popover width to the viewport and keeps the selected checkmark on the primary accent color, which makes the picker usable on narrow screens while preserving the standard selector behavior.

## Migration

No user action is required.
