## Summary

Adds a developer utility script for port-forwarding directly into a running agent pod in the cluster.

## Design

`scripts/agent-k8sfwd.sh <name>` kills any existing `kubectl port-forward` process, locates the running pod for the given agent across all namespaces, and forwards pod port 8090 to `localhost:8090`. The pod is found by matching `<name>-agent` against the pod list and selecting the most recent running instance.

## Migration

No action required. Script is a local developer tool with no impact on deployed infrastructure.
