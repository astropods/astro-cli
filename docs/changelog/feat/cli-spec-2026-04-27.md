## Summary

Groups the spec-related CLI commands under a new `ast spec` command group and refactors spec path resolution to be independent of cobra internals. This removes the `ast blueprint validate` command.

## Design

`validate`, `explain`, and `repair` move from top-level commands to subcommands of `ast spec`:

```
ast spec validate        # validate astropods.yml against the schema
ast spec explain         # human-readable explanation of the spec
ast spec repair          # check and repair project files (hidden)
```

The `--file/-f` flag is now a persistent flag on `spec`, shared by all three subcommands.

Spec path resolution (`resolveSpecPath`, `resolveSpecPathAndCwd`, `resolveSpecPathFromCwd`) is decoupled from `*cobra.Command` — callers pass the file path string directly rather than the command, making the helpers testable without cobra setup.

## Migration

`ast validate` → `ast spec validate`, `ast explain` → `ast spec explain`. The old top-level commands are removed.
