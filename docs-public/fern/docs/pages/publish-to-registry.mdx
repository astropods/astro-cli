Pushing your agent to the Astropods registry requires an account and authentication. If you don't have one, [sign up](https://astropods.com/signup).

## 1. Log in

```bash
ast login
```

## 2. Push

From your agent project directory, push the blueprint under a name:

```bash
ast blueprint push <name>
```

The name sets how the blueprint appears in the registry and does not need to match the `name` in `astropods.yml`. Blueprints are **private** by default.

### Visibility

```bash
ast blueprint push <name> --visibility public   # publish to the catalog
ast blueprint push <name> --visibility private  # keep private
```

You will be prompted to confirm when changing visibility.
