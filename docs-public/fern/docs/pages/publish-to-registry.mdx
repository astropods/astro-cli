Pushing your agent to the Astro AI registry requires an account and authentication. If you don't have an account, [sign up](https://astropods.ai/auth/login?screen_hint=sign-up).

## 1. Log in

Authenticate with your Astro AI account:

```bash
ast login
```

Complete the browser flow to link the CLI to your account. See [Authentication](/authentication) for details.

## 2. Push

From your agent project directory, push to the registry:

```bash
ast push
```

Your agent is then available in your account. By default, blueprints are **private**, visible only to you.

### Visibility

To make your blueprint publicly visible to everyone on the Astro AI catalog, pass `--public`:

```bash
ast push --public
```

You will be prompted to confirm before the blueprint is made public. To explicitly keep it private:

```bash
ast push --private
```

If a blueprint is already public and you push without a visibility flag, the public visibility is preserved automatically. Changing visibility in either direction always prompts for confirmation.
