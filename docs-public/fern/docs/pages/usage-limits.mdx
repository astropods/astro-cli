Every account can cap what it spends. Open **Manage limits** on the Pay-as-you-go card, on the billing page of your account settings.

There are two numbers:

- **Alert threshold** sends a notification and changes nothing else.
- **Spend limit** stops every agent in the account.

Leave a field empty for no limit. The alert threshold has to be below the spend limit, because the limit stops the account first.

## When a limit stops your agents

Every agent in the account stops. Deploying, restarting, and waking an agent are refused until the account starts again.

Three things start it again:

- Raise the limit above what the period has already used.
- Remove the limit.
- Wait for the next billing period, which resets what the period has counted.

Raising a limit takes effect immediately. Raising it to a number the period has already passed leaves the account stopped, because the account is still over the new limit.
