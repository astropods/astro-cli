When you list integrations in your [Agent Card](/agent-card) or `astropods.yml`, each string is matched against this registry. Known integrations are displayed with brand icons on your agent's detail page. Strings that don't match are displayed with a generic icon and the original text as a label.

Matching is case-insensitive. Each string is resolved against the `id`, `name`, and `aliases` columns below.
