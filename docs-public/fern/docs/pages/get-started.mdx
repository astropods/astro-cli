Go from zero to a running agent in three steps. Have the [CLI installed](/install-cli) and Docker ready. You can also [try a pre-built agent](#try-a-pre-built-agent).

<Steps>
  <Step title="Create an agent">
    Scaffold a new project:

    ```bash
    ast create
    ```
  </Step>
  <Step title="Configure your agent">
    Set all the inputs needed for your agent (e.g. `ANTHROPIC_API_KEY`):

    ```bash
    ast configure
    ```
  </Step>
  <Step title="Run your agent locally">
    To enable hot reload, add the following to your spec:

    ```yaml
    dev:
      command: bun --watch agent/index.ts
    ```

    Then start your agent:

    ```bash
    ast dev
    ```
  </Step>
  <Step title="Publish your agent">
    When you're ready to publish to the Astropods registry:

    ```bash
    ast login
    ast push
    ```
  </Step>
</Steps>

## Try a pre-built agent

We have built and shared several agents in the [astropods/agents](https://github.com/astropods/agents) open-source repo. You can try any of them with <code>ast dev</code>. Here's an example:

**GitHub Issue Analyzer** — Ingests GitHub issues from a repo into a Neo4j knowledge graph, enriches them with OpenAI analysis (categories, solutions, workarounds), and answers questions via Cypher queries and comment summarization. Requires `GITHUB_TOKEN` and `OPENAI_API_KEY`.

```bash
git clone https://github.com/astropods/agents.git
cd agents/github-issue-analyzer
ast configure   # set required API keys
ast dev
```
