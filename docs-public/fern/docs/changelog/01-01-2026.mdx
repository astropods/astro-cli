## Astro AI product docs

Initial release of public-facing Astro AI documentation, built with Fern.

### What's included

- **Get started** — Welcome, CLI install, get started with `ast`, and authentication
- **API reference** — Astro AI API generated from OpenAPI (list/get/register/push agents, config, profile)
- **Theme** — Teal/stone styling aligned with the Astro AI app

### API coverage

The API reference documents the agents and account endpoints used by the `ast` CLI and dashboard: public catalog, agent details, register and push builds, deployment config, and profile.
